**Premium KVM Sale 可以退款吗？**
不可以。该系列所有套餐均标注不退款，这是购买前必须接受的条款。

不需要。页面价格即成交价。优惠码只出现在 macOS VPS、EPYC NVMe VDS 等特定产品的活动里，且与三年付双倍配置活动互斥。

视 IP 段而定。曾有东京 SoftBank 用户的实测显示 Netflix 仅解锁自制剧、YouTube 和 Amazon Prime 正常，IPv4 有少量黑名单记录而 IPv6 很干净——同一机房不同 IP 段的结果都可能不同，别把单次测评当成保证。
